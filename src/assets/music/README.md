# Background music

Drop additional background tracks into this folder. Supported formats are
`.mp3`, `.ogg`, `.wav`, and `.m4a`.

The Vite build discovers files in this folder automatically. No playlist code
needs editing, although the development server may need restarting after new
files are added.

Use descriptive filenames in the form `artist-track-title-id.mp3`. The player
turns the filename into the displayed artist and track title.

Only add music that the project is licensed to use, and retain any required
attribution outside this folder.
